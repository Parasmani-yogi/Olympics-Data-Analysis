# Olympic Analysis

## Overview
This project provides an interactive analysis of the Summer Olympics dataset (up to 2016).  
Using Python libraries such as **Pandas**, **NumPy**, **Seaborn**, and **Plotly**, the project explores historical performance trends across countries, athletes, and sports.  

A **Streamlit web application** has been developed for an intuitive interface, and the app is also deployed on **AWS EC2** for online access.

---

## Features
- Exploratory Data Analysis (EDA) to analyze medals, countries, and athlete performance.  
- Country-wise insights to compare Olympic achievements across nations.  
- Athlete-wise analysis to study performance trends by athletes and gender.  
- Sport-wise trends to explore the evolution of different sports over time.  
- Deployed on AWS EC2 for global accessibility.

---

## Tech Stack
- **Language:** Python  
- **Libraries:** Pandas, NumPy, Seaborn, Plotly, Matplotlib  
- **Framework:** Streamlit  
- **Deployment:** AWS EC2
